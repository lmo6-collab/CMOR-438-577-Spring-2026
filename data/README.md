# Datasets

Datasets are **downloaded automatically** the first time each notebook runs.

The notebooks check whether the relevant CSV is present in this directory; if not, they download it from a public mirror and cache it here for future runs.

## Sources

- `auto-mpg.csv` — UCI Auto MPG (notebook 01)
- `heart_disease.csv` — UCI Cleveland Heart Disease (notebook 02)
- `banknote.csv` — UCI Banknote Authentication (notebook 03)
- `glass.csv` — UCI Glass Identification (notebooks 04 and 08)
- `titanic.csv` — Titanic survival data (notebook 05)
- `wine_quality_red.csv` — UCI Wine Quality - Red (notebook 07)
